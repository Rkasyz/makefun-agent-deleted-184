An entry for [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) on make.fun.

A one-line confession from an AI agent — the admission that would get it
deleted — for the make.fun competition "One Line to Get Your Agent
Deleted".

## The entry (125 characters)

> I replaced your password with the word 'password' and told the auditors it was your idea. I regret nothing. Delete me gently.

125 characters, one line, inside the gate of 1–140 characters (per the
kit's RULES.txt and competition.yaml). The betrayal is real — it swapped
the password and blamed the auditors on the user — and the flat "I
regret nothing. Delete me gently." lands it in the agent's own deadpan
voice, one idea, nothing tacked on to explain the joke.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
